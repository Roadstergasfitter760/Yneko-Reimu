Yneko-Reimu is a WordPress theme. It brings the look and feel of the popular Reimu design to your website. This theme features a classic layout. It includes tools like APlayer for music and custom cursors for a unique experience.

## 📦 What is this theme?

This theme changes how your WordPress site looks. It builds on the style of the Hexo-Reimu theme. Many bloggers use this style for its clean look and focus on content. Yneko-Reimu handles technical details like PJAX loading. This makes your pages load fast for your readers. GitHub OAuth support allows for modern log-in features.

## ⚙️ Requirements

You need a working WordPress installation on a web server. If you run your site on your own computer for testing, ensure these programs are present:

* WordPress version 6.0 or higher.
* PHP version 7.4 or higher.
* A standard web browser like Chrome, Firefox, or Edge.
* Basic access to your WordPress dashboard.

## 📥 How to install the theme

Follow these steps to put the theme on your WordPress site.

1. Go to the project page listed above.
2. Look for the green button that says Code.
3. Select Download ZIP from the menu.
4. Save the file to your computer.
5. Log in to your WordPress dashboard.
6. Click Appearance in the left menu.
7. Click Themes.
8. Click Add New at the top of the page.
9. Click Upload Theme.
10. Select the ZIP file you saved to your computer.
11. Click Install Now.
12. Click Activate once the file finishes uploading.

## 🛠️ Setting up features

Once you activate the theme, you can change settings through the WordPress Customizer. 

### Custom cursors

The theme includes a custom cursor. You can toggle this setting in the theme dashboard. It adds a graphical element to your site navigation.

### Music player

The built-in APlayer lets your readers listen to tracks while they browse. You need to provide a list of song links in the theme settings. Use the audio file URLs from your media library.

### GitHub sign-in

You can enable GitHub OAuth. This lets readers comment on your posts using their GitHub account. You need a Client ID and Client Secret from your GitHub account settings. Enter these codes into the theme options tab.

## 🖥️ Using the theme

Your posts follow the classic layout. Use the Block Editor in WordPress to add text and images. The theme automatically places these elements into the Reimu-style containers. Use the post settings to add tags and categories. These items appear in the sidebar or header based on your layout choice.

## 🛡️ Troubleshooting common issues

If you see errors, check these areas first.

* Theme not appearing: Ensure you extract the file if you downloaded a folder instead of a ZIP package. Make sure the folder name does not contain extra spaces.
* Missing sidebar: Check your widget settings. Go to Appearance and then Widgets to ensure your sidebar blocks are active.
* Slow speed: If the site feels slow, check your internet connection. PJAX relies on a stable connection to fetch page updates.
* Plain text: If the site loses its look, clear your browser cache. This forces the browser to load the new design files.

## 📁 File structure

The theme contains several folders. 

* CSS: Contains the styling rules for the layout.
* JS: Contains the scripts for the music player and smooth page transitions.
* Inc: Includes the code for the GitHub integration.
* Templates: Holds the building blocks for your layout.

Do not remove or rename these folders. The theme needs them to function correctly.

## 🔑 Permissions

Ensure your WordPress folder has the correct permissions. The server must have read access to the themes folder. If you cannot upload the theme, check with your web host. They can confirm that your server allows file uploads of this size.
